# claude-statusline

Статусная строка для [Claude Code](https://claude.com/claude-code): две строки, разбитые
на колонки, — проект, лимиты подписки, контекст с разбором по составу и стоимость сессии.

```
kad_reserv_v2        5h █░░░░░░░░░ 8% (2h 17m)         ctx █████████░░░░░░░░░░░░░░░░░░░░░ 45% (134k/300k)   cmp 1/3   $1.23
Opus 5 (1M · high)   (cache 99% · in 0% · out 1%)      | base 10% · 30k | hist 35% · 104k | free 55% · 166k
```

Каждая колонка — пара «сверху/снизу», обе строки выравниваются по ширине колонки:

| Сверху | Снизу |
| --- | --- |
| проект | модель, окно контекста, уровень effort |
| лимит 5 часов | лимит 7 дней |
| контекст | разбор контекстного бара |
| счётчик `/compact` | — |
| стоимость сессии | — |

Иконок-эмодзи в строке намеренно нет: в терминалах/шрифтах без их поддержки они
рисуются квадратиками-заглушками и в некоторых TUI-рендерах (например, фуллскрин-режим
Claude Code) при перерисовке могут оставлять visual-мусор от предыдущего кадра. Подписи
(`5h`, `ctx`, `cmp` и т.д.) и так однозначно читаются.

## Чем отличается бар контекста

Обычно статуслайны показывают заполнение относительно окна модели. Здесь бар меряется
до **порога автокомпакта** (`autoCompactWindow` из `settings.json`) — то есть до момента,
когда диалог реально начнёт сжиматься, а не до формального предела модели.

Бар разбит по цветам на три части:

- **base** (синий) — несжимаемое: системный промпт, описания инструментов, `CLAUDE.md`,
  скиллы. Оценивается по первому ответу модели в текущем транскрипте и кэшируется
  в `~/.claude/cache/`, потому что транскрипт бывает на десятки мегабайт.
- **hist** (зелёный → жёлтый → красный по мере заполнения) — сам диалог.
- **free** (серый) — сколько осталось до автокомпакта.

Цвет процентов: зелёный < 50 %, жёлтый 50–79 %, красный ≥ 80 %. Время до сброса лимита —
голубым, чтобы не путалось с процентами.

## Счётчик `/compact`

Блок `cmp N/3` считает, сколько раз текущая сессия уже прошла через `/compact`
(ручной или автоматический) — ищет в транскрипте отметки `isCompactSummary`.
Досчитывается инкрементально (кэш в `~/.claude/cache/`), полный транскрипт заново не
перечитывается.

**Больше 3 компактов подряд не рекомендуется** — модель после нескольких сжатий подряд
теряет часть деталей исходного диалога, и качество ответов начинает проседать. Как
только счётчик достигает `3/3` (цвет становится красным), лучше не компактить дальше, а
сбросить контекст командой `/clear` и начать раздел заново — так модель снова видит
происходящее без искажений от повторных пересказов.

При достижении `3/3` скрипт один раз (не при каждой перерисовке) шлёт системное
уведомление со звуком через `osascript`/`afplay` — сейчас это реализовано для macOS.

## Установка

Требуется `python3` — больше ничего, все зависимости стандартная библиотека.

```bash
git clone git@github.com:UIbodulloev/claude-statusline.git
cp claude-statusline/statusline.py claude-statusline/statusline-command.sh ~/.claude/
chmod +x ~/.claude/statusline-command.sh
```

Дальше в `~/.claude/settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "bash \"$HOME/.claude/statusline-command.sh\""
  }
}
```

Путь задан относительно `$HOME`, поэтому один и тот же `settings.json` работает
и локально, и на сервере под другим пользователем.

Чтобы бар контекста учитывал порог автокомпакта, в том же файле должно быть:

```json
{
  "autoCompactEnabled": true,
  "autoCompactWindow": 300000
}
```

Если `autoCompactEnabled` выставлен в `false`, бар меряется до полного окна модели.

## Настройка

Всё правится вверху `statusline.py`:

- `BAR_W` — ширина баров лимитов (по умолчанию 20);
- `CTX_BAR_W` — ширина бара контекста (30);
- `SEP` — отступ между колонками;
- константы `C_*` — цвета, заданы через truecolor-последовательности (`fg(r, g, b)`),
  так что нужен терминал с поддержкой 24-битного цвета.

Колонка исчезает, если для неё нет данных: например, без лимитов подписки не будет
блока `5h`/`7d`, а при нулевой стоимости — блока с деньгами.

## Как это работает

Claude Code отдаёт скрипту JSON на stdin (модель, рабочая директория, лимиты, счётчики
контекста, путь к транскрипту, стоимость), а всё, что скрипт напишет в stdout,
показывается под строкой ввода. Скрипт ничего не пишет за пределами `~/.claude/cache/`
и не ходит в сеть — единственное исключение: при достижении лимита `/compact`
(см. выше) он один раз вызывает `osascript`/`afplay`, чтобы показать системное
уведомление со звуком.
